# tokenimizer.github.io

Personal journal for Tokenimizer, principal developer at Hidden Tokens. Built with Jekyll and hosted on GitHub Pages.

## Write a post

Create a Markdown file in `_posts` named `YYYY-MM-DD-short-title.md`:

```markdown
---
title: A journal entry
date: 2026-11-06 12:00:00 +0000
description: A short summary for search and social previews.
tags: [notes, setup]
---

Write the entry here using Markdown.
```

Published posts automatically appear on the home page and journal archive, with individual social metadata, RSS, sitemap, and `llms.txt` entries.

## Preview locally

Run `jekyll serve` and open `http://localhost:4000`.
